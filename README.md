🐍 NumPy & Pandas Practice

📌 Project Overview
This repository is part of my Python learning journey and focuses on fundamental NumPy array operations and pandas Series/DataFrame handling. The exercises were completed in a Jupyter/Colab notebook and are organized as practical coding tasks.

* NumPy array creation and attributes
* Array slicing and indexing
* Vectorized array operations
* Pandas Series creation and indexing
* Pandas DataFrame creation and exploration
* Filtering, grouping, and aggregating data
* Adding, updating, and dropping columns/rows

🎯 Objectives
* Understand how to create and inspect NumPy arrays (shape, size, dtype, ndim)
* Perform vectorized calculations on arrays
* Practice array slicing techniques
* Create and access pandas Series using .iloc
* Build and explore pandas DataFrames
* Apply filtering, grouping, and aggregation methods
* Modify DataFrames by adding, updating, and dropping data

🛠️ Tech Stack
* Python 3
* NumPy
* Pandas
* Jupyter Notebook / Google Colab

📂 File Structure
Numpy_and_panda_series.ipynb → Main notebook containing all exercises

🚀 How to Run
1. Clone this repository
2. Install dependencies: pip install numpy pandas jupyter
3. Open the notebook: jupyter notebook Numpy_and_panda_series.ipynb
4. Run the cells in order

📖 Topics Covered
1️⃣ NumPy Arrays
* Creating 1D and 2D arrays
* Checking shape, size, dtype, ndim
* Converting units with vectorized math
* Slicing arrays (first n, last n, middle range)

2️⃣ Pandas Series
* Creating a Series with a custom index
* Accessing values with .iloc

3️⃣ Pandas DataFrames
* Creating a DataFrame from a dictionary
* Exploring data with .head(), .tail(), .info
* Selecting columns and filtering rows
* Using .value_counts(), .unique(), .groupby()
* Updating values with .loc
* Adding and dropping columns/rows
